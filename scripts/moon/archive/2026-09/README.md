# Historical Factor 1 MOON analysis scripts

These files preserve the exploratory TF-to-lipid analysis used to select the manuscript network in September 2026. The scripts and templates were moved here **without changing their bytes**. `path_migration_manifest.csv` records every original repository path, archived path, SHA256 digest and byte count. The archive-local `.gitattributes` preserves the template CSV's original CRLF bytes so its digest survives Git checkout; the other 28 archived files exactly match their committed originals. The active compatibility helpers remain at `scripts/moon/moon_safe_helpers.R`.

Use the current entry point `scripts/moon/run_factor1_tf_to_lipid.R` and the workflow documentation in `scripts/moon/README.md` for the selected result. This archive documents how the pilot, parameter search and methodological audits developed; it is not the active workflow.

## Path and software caveats

Most archived scripts contain the former `results/cosmos_*` locations. The corresponding frozen artifacts now reside under `results/causal_modelling/cosmos_*`. Archived RDS objects and CSV/JSON manifests can also contain old `run_dir`, `topology_reference` or absolute path strings. Those strings document their original execution context; they are not evidence that the old paths still exist.

The scripts also contain their original `source("scripts/moon/...")` calls and sibling-script assumptions. Moving the files did not update those references. Do not execute a command copied from this archive as a current reproduction command: it may fail or create obsolete output directories. Use the active workflow or an explicit, reviewed migration adapter. Do not edit frozen RDS objects or manifests merely to replace historical paths.

The archived parameter-search cache checks configuration names but does not fully validate input or software hashes before reusing a state. Some script hashes in historical run manifests differ from the final exploratory versions archived here; the move preserves the pre-cleanup working tree, not a claim that every file is the exact source snapshot of every historical run. The active workflow records its own inputs, settings, software and replay comparison.

The recorded baseline environment was R 4.6.1, cosmosR 1.21.2, decoupleR 2.17.0 and igraph 2.3.3. Numerical results should be checked against the frozen manuscript state when replayed under another environment. The historical MOFA audit additionally uses Python, numpy and h5py. The exporter uses Python's standard library and invokes R for plots.

The selected baseline uses topology pruning distance 6, MOON depth 4, protected input/regulon identifiers during same-child compression, a fixed compression map through the RNA-coherence loop, and strict primary/secondary score cutoffs 1.85/0.55. It yields 388 signed edges and 153 original-ID nodes. The larger parameter search and stronger-compression checks remain ancillary evidence rather than prerequisites for every replay.

## Archive verification

SHA256 digests were checked immediately after relocation against the bytes read before each move. No R source was modified and no historical analysis was rerun for this archival operation. To recheck the archive from the repository root:

```sh
python3 - <<'PY'
import csv
import hashlib
from pathlib import Path
manifest = Path("scripts/moon/archive/2026-09/path_migration_manifest.csv")
rows = list(csv.DictReader(manifest.open()))
for row in rows:
    path = Path(row["archived_path"])
    assert path.stat().st_size == int(row["bytes"]), path
    assert hashlib.sha256(path.read_bytes()).hexdigest() == row["sha256"], path
print(f"Verified {len(rows)} unchanged archived files.")
PY
```
