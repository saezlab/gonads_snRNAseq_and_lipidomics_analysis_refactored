# Analysis of snRNA, lipidomic and proteomic data from intersex mice models

Study of the effect of gonadal hormones on hepatocyte, notably with repsect to lipid metabolism. The mice models are used to detangled the effect of Y chromosome from the gonadal hormone themselves.

Plan is to analyse the pseudobulk data using the footprint and pathway analysis workflow, and integrate with lipidomic data by combining LINEX2 and COSMOS.
